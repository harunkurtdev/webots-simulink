# Pirana USV


![PiranaUSV](../assets/videos/pirana/video1.gif)
![PiranaUSV2](../assets/videos/pirana/video2.gif)

The Pirana USV (Unmanned Surface Vehicle) is a versatile autonomous marine platform developed by MKE (Mechanical and Chemical Industry Corporation) for various surface operations. Designed for both civilian and defense applications, the Pirana USV features advanced navigation, remote control capabilities, and modular payload options.

## Key Features

- **Autonomous Navigation:** Equipped with GPS and onboard sensors for precise path following and obstacle avoidance.
- **Remote Operation:** Can be controlled via secure wireless communication for real-time mission updates.
- **Modular Design:** Supports different payloads such as cameras, sonar, and environmental sensors.
- **Robust Hull:** Built for stability and durability in challenging marine environments.
- **Applications:** Surveillance, reconnaissance, environmental monitoring, and search & rescue.

The Pirana USV demonstrates the growing capabilities of unmanned marine systems, offering reliable performance for a wide range of missions.
